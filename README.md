# rollimario.eu

Portfolio of Mario – architecture and photography.

- `index.html` – the whole site (layout, styles, scripts)
- `clouds/` – point clouds for the start page (binary: int16 x/y/z, then uint8 weight)
- `p/<project>/` – images, drawings and point clouds per project
- `assets/` – font and images of the placeholder projects

Hosted on Netlify (no build step, publish directory = repository root).
Not yet public: `robots.txt` and the robots meta tag block search engines until launch.
